# ERR-51039 Invalid Protocol
Source: https://docs.altibase.com/display/FAQE/ERR-51039+Invalid+Protocol
Updated: 2014-11-19T17:10:42.000+0900

- [Version](#ERR-51039InvalidProtocol-Version)

- [Reference](#ERR-51039InvalidProtocol-Reference)

## Version

All versions

## Explanation

Unable to connect to database.

## Cause

This error occurs if the ALTIBASE CM_PROTOCOL version is different.

## Action

Set the Client CM_PROTOCOL version according to CM_PROTOCOL of the database server.

N/A
