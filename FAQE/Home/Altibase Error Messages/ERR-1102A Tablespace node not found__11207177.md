# ERR-1102A Tablespace node not found
Source: https://docs.altibase.com/display/FAQE/ERR-1102A+Tablespace+node+not+found
Updated: 2017-02-01T16:06:57.000+0900

- [Version](#ERR-1102ATablespacenodenotfound-Version) - [Explanation](#ERR-1102ATablespacenodenotfound-Explanation) - [Cause](#ERR-1102ATablespacenodenotfound-Cause) - [Action](#ERR-1102ATablespacenodenotfound-Action) - [Reference](#ERR-1102ATablespacenodenotfound-Reference)

## Version

All versions

## Explanation

Unable to execute query.

## Cause

An attempt has been made to create a table to a tablespace that does not exist.

## Action

Check the name of the tablespace to which the table is to be saved.
