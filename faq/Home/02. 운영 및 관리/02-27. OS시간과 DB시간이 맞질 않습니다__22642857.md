# **개요**

---

**DB 서버 운영 중(***알티베이스가 기동된 상태***)** OS time-zone 변경 또는 DST 적용 시 OS시간과 DB(sysdate) 시간이 맞지 않을 수 있습니다.

이럴경우 정확한 시간 동기화를 위해 DB 재기동이 필요합니다.

(참고 : 본 문서는 Linux OS를 기준으로 작성되었으며, 다른 Unix시스템은 확인 및 변경방법이 다를 수 있습니다. )
