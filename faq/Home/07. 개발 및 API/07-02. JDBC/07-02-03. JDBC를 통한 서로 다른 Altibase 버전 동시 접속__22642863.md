# 07-02-03. JDBC를 통한 서로 다른 Altibase 버전 동시 접속

# 개요

---

Altibase JDBC Driver를 이용하여 다른 버전의 Altibase에 접속할 수 있는 방법을 설명 한다.

Altibase는 서로 다른 Altibase 에 접속할 수 있도록 추가적인 jdbc driver를 제공한다. 본 문서는 Altibase 7.3 버전을 기준으로 설명하며, 7.3에서 제공되는 추가적인 드라이버 파일은 Altibase7_3.jar 이다.

Application 에서 Class.forName() 메소드를 이용하여 Driver 클래스를 로딩할 때 클래스 명을 Altibase.jdbc.driver.AltibaseDriver와 Altibase7_3.jdbc.driver.AltibaseDriver 로 구분하여 지정하면 상이한 Altibase 버전 간에 접속하여 사용할 수 있다.

# Driver 위치

---

Diver의 위치는 $ALTIBASE_HOME/lib이며 7.3 버전의 경우 파일명은 Altibase7_3.jar이다.

```
$ ls -al
-rw-rw-rw- 1 altibase altibase  509530 Apr 20 11:10 Altibase7_3.jar
-rw-rw-rw- 1 altibase altibase  506968 Apr 20 11:10 Altibase.jar
```

# 버전 확인

---

타 버전 확인에 접속하기 위한 Driver 확인

```
$ java -jar Altibase7_3.jar
Altibase 7.3.0.1.0 with CMP 7.1.8 for JDBC 4.2 compiled with JDK 8
```

# 사용 예제

---

예제는 7.1 버전과 7.3 버전의 동시 접속을 설명한다.

7.1 버전의 $ALTIBASE_HOME/lib/Altibase.jar 파일을 가지고 오고 7.3버전에서는 $ALTIBASE_HOME/lib/Altibase7_3.jar 파일을 가지고 와서 사용하면 된다.

```
// - AltibaseMultiversionConnection.java 파일
// ALTIBASE 7.3 Driver 클래스 - Altibase7_3.jar 파일 사용
Class.forName("Altibase7_3.jdbc.driver.AltibaseDriver”);
// ALTIBASE 7.1 Driver 클래스 - Altibase.jar 파일 사용
Class.forName("Altibase.jdbc.driver.AltibaseDriver");
//ALTIBASE 7.3 버전 URL
String db_url1 = "jdbc:Altibase://192.168.1.111:20300/mydb";
//ALTIBASE 7.1 버전 URL
String db_url2 = "jdbc:Altibase://192.168.1.222:20300/mydb";
```
