# Job J003: Technical docs: operations and administration

## Goal

Compare Korean DOCK configuration, operation, startup/shutdown, system resource, memory, CPU, monitoring, and OS utility documents against English arch documents, then update English from Korean where needed.

## Scope

- Work only on this job.
- Read the existing project instructions before editing.
- Do not revert unrelated user changes.
- Before editing, stop if there are uncommitted project files from a previous job.
- Complete the scoped job without asking for step-by-step confirmation unless blocked or unsafe.


## Shared Requirements

Before planning or editing, read and follow these files:

- `AGENTS.md`
- `LLM_REFERENCE_REVIEW_PLAN.md`
- `KO_EN_DOC_REVIEW_REPORT.md`
- `.codex-jobs/ko-en-doc-coverage/jobs.md`
- `.codex-jobs/ko-en-doc-coverage/workflow-requirements.md`

The final workflow goal is that all English documents in scope include the content from the corresponding Korean documents. Korean documents are authoritative, and Korean documents must not be deleted.

## Required Steps

1. Reconfirm the job requirement and boundary.
2. Inspect the relevant files and existing patterns.
3. Write or update a short design note if this job changes behavior, architecture, or documentation structure.
4. Draft or edit the scoped documentation.
5. Self-review for correctness, omissions, broken links, inconsistent terminology, and unclear text.
6. Apply fixes from the review.
7. Run documentation checks, link checks, formatting checks, or grep-based consistency checks appropriate for this job.
8. Run the targeted verification commands.
9. Fix failures and rerun the relevant checks.
10. Review the final diff after checks pass.
11. Commit the completed job with a focused message. Do not report success without a commit.

## Acceptance Criteria

- The goal above is complete.
- Relevant checks have passed or any skipped checks are explicitly explained.
- The final review passed.
- The job result is committed, and project files are clean after the commit.
