# Job G003: GPT retrieval hardening and answer routing

## Goal

Improve the encyclopedia bundle for GPTs retrieval with front matter, routing index, exact-identifier guidance, and self-contained answer rules without removing source traceability.

## Scope

Work only on GPT retrieval hardening for the generated encyclopedia.

Prefer changing the generator and regenerating the encyclopedia rather than manually editing generated output.

You may edit:

- `llm-reference/gpts-upload/build-gpts-knowledge-bundles.py`
- `llm-reference/gpts-upload/Altibase_GPT_Knowledge_Encyclopedia.md`
- `llm-reference/gpts-upload/README.md` only if needed

## Required Steps

1. Inspect the generated encyclopedia front matter and included document boundaries.
2. Improve the top of the encyclopedia for GPTs retrieval and answer behavior.
3. Add or generate an answer routing index covering:
   - Installation, patch, upgrade, database creation, and platform setup.
   - Architecture, storage, checkpoints, logs, and disk concepts.
   - Operation, administration, security, sessions, charset, and configuration.
   - Backup, recovery, failure response, and utilities.
   - Replication and HA.
   - Monitoring, diagnostics, CPU, memory, locks, and system views.
   - Troubleshooting and error messages.
   - SQL, stored procedures, optimizer, indexing, partitioning, and performance.
   - Development, APRE, JDBC, ODBC, ADO.NET, PHP, and client APIs.
   - WAS/framework integration.
   - Migration, conversion, and tooling.
   - Terminology and multilingual answer preservation.
4. Add exact-identifier rules near the top.
5. Add source-confidence and limitation-label rules near the top.
6. Ensure no rule tells GPTs to open original source files.
7. Regenerate the encyclopedia from the script.
8. Run verification.
9. Review the final diff.
10. Commit the completed job with a focused message.

## Acceptance Criteria

- The encyclopedia top matter includes answer rules, routing index, exact-identifier rules, and limitation-label rules.
- The encyclopedia still includes all 12 topic documents exactly once in full.
- Source paths remain present as traceability labels.
- No top-level instruction implies original source files are required at GPT answer time.
- `python3 llm-reference/gpts-upload/build-gpts-knowledge-bundles.py` passes.
- `python3 -m json.tool manifest.json >/tmp/aid-manifest-check.json` passes.
- `git diff --check` passes.
- The artifact scan has no matches; `rg` exit code 1 is the passing no-match result.
- The job result is committed, and project files are clean after the commit.
