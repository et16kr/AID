# Job G005: Final GPTs readiness validation

## Goal

Run final validation proving the generated 1-2 files are complete, self-contained, source-traceable, and ready for GPTs upload.

## Scope

Work only on final GPTs upload readiness validation and report generation.

You may edit:

- `llm-reference/gpts-upload/GPTS_READINESS_REPORT.md`
- `llm-reference/gpts-upload/README.md` only for final status or links
- Generated bundle files only if validation finds a blocking defect and the fix is small and clearly scoped

## Required Steps

1. Reconfirm expected outputs from `workflow-requirements.md`.
2. Run final validation checks:
   - Manifest JSON parse.
   - `git diff --check`.
   - Generator rerun.
   - Required output presence.
   - Included document boundary count.
   - All 12 topic files included exactly once.
   - `COMPLETE_REFERENCE_PACKAGE` present.
   - `GPTS_UPLOAD_READY` final report decision when all checks pass.
   - No unresolved status-field `recheck_required` rows in coverage ledgers.
   - Artifact scan no-match.
   - Upload manifest no more than 2 Altibase GPTs upload files.
   - `python3 llm-reference/gpts-upload/validate-gpts-knowledge.py --mode full`.
3. Fix small blocking defects if safe; otherwise mark final decision `GPTS_RECHECK_REQUIRED`.
4. Create `GPTS_READINESS_REPORT.md` with:
   - Final decision.
   - Exact GPTs upload file list.
   - Validation command results.
   - Size summary.
   - Remaining accepted limitations.
   - Automated validation decision.
   - Statement that original source trees are not GPT answer-time dependencies.
5. Run `python3 llm-reference/gpts-upload/validate-gpts-knowledge.py --mode final`.
6. Review the final diff.
7. Commit the completed job with a focused message.

## Acceptance Criteria

- `GPTS_READINESS_REPORT.md` exists.
- The report final decision is `GPTS_UPLOAD_READY` unless a real blocker remains.
- The report lists `Altibase_GPT_Knowledge_Encyclopedia.md` as the required upload file.
- The report lists `Altibase_GPT_Knowledge_Audit.md` only as optional/internal.
- The report states that human review starts only after automated validation passes.
- All validation checks pass or a blocker is explicitly recorded as `GPTS_RECHECK_REQUIRED`.
- The job result is committed, and project files are clean after the commit.
