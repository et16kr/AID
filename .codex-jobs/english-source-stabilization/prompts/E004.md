# Job E004: Legacy Attachment Inventory

## Goal

Inventory legacy attachment labels that have no downloadable source URL and record them without inventing links.

## Scope

- Primary evidence sources: `semantic-coverage/matrices/S019-technical-attachments-and-source-links.tsv`, `semantic-coverage/matrices/S031-faq-attachments-english-only-classification.tsv`, and their notes.
- Additional scan targets: `arch/Home`, `FAQE/Home`, and `source-stabilization`.
- Evidence target: `source-stabilization/legacy-attachments.tsv`.
- Do not create or rewrite attachment URLs.

## Required Work

1. Run the worktree handoff check from the shared addendum.
2. Inspect S019 and S031 matrix and note evidence for legacy labels and source limitations.
3. Scan English sources for legacy placeholder wording and hash-only attachment remnants.
4. Add one inventory row per legacy label with source path, label, related Korean or evidence path, classification, action `no downloadable URL in source`, and risk.
5. Verify live English source files do not contain hash-only Markdown attachment links.
6. Run standard verification.
7. Commit the result with message `Inventory legacy attachment labels`.

## Acceptance Criteria

- `source-stabilization/legacy-attachments.tsv` covers all legacy no-download labels found in Phase 1 evidence.
- No fake or guessed attachment URL is introduced.
- Rows distinguish source limitation from URL-backed attachments.
- Standard verification passes and project files are clean after the commit.
