# Job E003: Markdown Artifact Cleanup

## Goal

Verify that English sources and stabilization evidence have no unhandled Markdown link or macro-export artifacts.

## Scope

- Scan targets: `arch/Home`, `FAQE/Home`, `semantic-coverage`, and `source-stabilization`.
- Evidence target: `source-stabilization/markdown-artifacts.tsv`.
- Allowed edits: live English-source artifact fixes and evidence wording that prevents false validation failures while preserving meaning.
- Do not remove meaningful attachment or macro history from evidence.

## Required Work

1. Run the worktree handoff check from the shared addendum.
2. Run `rg -n "\[\]\(|Error rendering macro|Unknown macro|unknown-macro|\]\(#\)" arch/Home FAQE/Home semantic-coverage source-stabilization`.
3. Record each hit in `source-stabilization/markdown-artifacts.tsv` with path, line, pattern class, action, and risk.
4. Fix live English-source defects when the correct text is clear.
5. If evidence files contain historical artifact wording, rephrase only enough to make validation unambiguous.
6. Update `manifest.json` metadata for edited Markdown source files if content changed.
7. Rerun the artifact scan or a narrowed scan and record the passing result.
8. Commit the result with message `Clean Markdown artifact evidence`.

## Acceptance Criteria

- No unclassified artifact hit remains in live English source files.
- Any intentional evidence hit is documented with a narrower passing scan.
- `source-stabilization/markdown-artifacts.tsv` records findings and actions.
- Standard verification passes and project files are clean after the commit.
