# Job E008: Manifest And Source Metadata Check

## Goal

Validate `manifest.json` against current source files and normalize metadata when needed.

## Scope

- Source inputs: `manifest.json`, `DOCK/Home`, `faq/Home`, `arch/Home`, `FAQE/Home`, and Phase 2 evidence.
- Evidence target: `source-stabilization/manifest-metadata.tsv`.
- Use the exact schema and status values from `workflow-requirements.md`.
- Allowed edits: `manifest.json` metadata fields needed to match current Markdown files.

## Required Work

1. Run the worktree handoff check from the shared addendum.
2. Validate `manifest.json` with `python3 -m json.tool`.
3. Check manifest source paths using the same path-normalization assumptions recorded in Phase 1.
4. Compare `body_chars` and `word_count` values against current Markdown file contents for all page entries or for every entry affected by Phase 2 source edits.
5. Normalize stale metadata.
6. Record checked counts, mismatches, fixes, and remaining risks in `source-stabilization/manifest-metadata.tsv`.
7. Run standard verification.
8. Commit the result with message `Validate English source manifest metadata`.

## Acceptance Criteria

- `manifest.json` is valid JSON.
- Checked manifest paths resolve or are recorded with a concrete source limitation.
- Checked `body_chars` and `word_count` values match current files after any needed normalization.
- Source document counts remain stable.
- Standard verification passes and project files are clean after the commit.
