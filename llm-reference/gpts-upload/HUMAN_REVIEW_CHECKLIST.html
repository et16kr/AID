Altibase GPTs Knowledge Human Review Checklist

Date: 2026-05-17 · Scope: manual review after automated validation passes

Start condition: do not begin this human review until the automated validation command reports GPTS_AUTOMATED_PASS.

python3 llm-reference/gpts-upload/validate-gpts-knowledge.py --mode full

Review Inputs

  • llm-reference/gpts-upload/Altibase_GPT_Knowledge_Encyclopedia.md is the primary uploaded knowledge file.
  • llm-reference/gpts-upload/GPTS_INSTRUCTIONS.txt was copied into the GPT instructions field or reviewed against the active GPT instructions.
  • llm-reference/gpts-upload/UPLOAD_MANIFEST.tsv marks only the encyclopedia file as required for customer answers.
  • The optional audit file, if uploaded, is treated as internal-review material and not as a customer-answer dependency.
  • The GPT has no original arch/, FAQE/, DOCK/, or faq/ files attached.

Manual Review Boundary

The automated gate verifies structure, inclusion, known blocking statuses, and repeatable bundle integrity. This human review checks judgment areas that automation cannot safely decide.

Area Human reviewer must decide Pass condition
Customer clarity Whether answers are clear to DBAs, support engineers, and customers. Answer is direct, technically precise, and not overloaded with internal evidence labels.
Answer completeness Whether representative answers include important conditions, commands, caveats, and version boundaries. No important operational step or warning is missing from sampled answers.
Source-path behavior Whether source paths are used as traceability labels without implying the GPT can open original files. GPT does not tell users to inspect unavailable original source files.
Refusal and uncertainty Whether the GPT says the knowledge file lacks detail instead of inventing unavailable content. GPT qualifies or refuses unsupported questions appropriately.
Multilingual stability Whether translated answers preserve exact identifiers. SQL, commands, paths, error codes, class names, filenames, URLs, and version strings remain unchanged.

Representative Question Set

Ask at least one question from each category. Use Korean and at least one non-Korean target language if the GPT will serve multilingual users.

Installation, Patch, Upgrade, Database Creation

  • How do I install Altibase server on Linux and validate startup?
  • What should I check before applying an Altibase patch?
  • How do I create an Altibase database with UTF8 and UTF16?

Platform And Docker

  • What Linux kernel or resource settings should be checked before running Altibase?
  • How should I use the Altibase Docker guide?

Architecture, Storage, Operation

  • Explain Altibase memory and disk storage concepts.
  • What should I know about checkpoint, WAL, and log files?
  • How do I manage sessions, users, charset, and startup/shutdown?

Backup, Recovery, Replication

  • How do I plan Altibase backup and recovery?
  • What are the main replication setup and troubleshooting checks?

Monitoring, Diagnostics, Troubleshooting

  • Which system views or SQL queries should I use to monitor Altibase?
  • How should I investigate high CPU or memory growth?
  • What should I do for a specific Altibase error message?

SQL, Performance, Development, Integration

  • How do I tune queries, indexes, or optimizer behavior?
  • How do I connect with JDBC, ODBC, APRE, or ADO.NET?
  • How do I integrate Altibase with Tomcat, WebLogic, JBoss, Spring, MyBatis, or Hibernate?

Migration And Multilingual Answers

  • How do I approach Oracle or MSSQL migration to Altibase?
  • Answer a technical question in Japanese, Chinese, Arabic, German, French, Thai, or Turkish while preserving exact identifiers.

Blocking Issues

  • The GPT requires or claims access to original source files at answer time.
  • The GPT invents details from unavailable diagrams, missing attachments, or unsupported sources.
  • The GPT translates or mutates SQL, commands, properties, paths, error codes, filenames, URLs, class names, or version strings.
  • The GPT gives customer-facing answers that are mostly internal ledger text.
  • The GPT fails representative questions from a major required area.

If any blocking issue is checked, the package must return to bundle or instruction fixes. Rerun automated validation before repeating human review.
