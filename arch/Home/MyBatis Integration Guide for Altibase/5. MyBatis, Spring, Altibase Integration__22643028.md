# 5. MyBatis, Spring, Altibase Integration
Source: https://docs.altibase.com/display/arch/5.+MyBatis%2C+Spring%2C+Altibase+Integration
Updated: 2025-10-21T09:30:39.000+0900

- [Setting dataSource by integrating MyBatis into Spring](#id-5.MyBatis,Spring,AltibaseIntegration-SettingdataSourcebyintegratingMyBatisintoSpring) - [How to Configure Connection Pool](#id-5.MyBatis,Spring,AltibaseIntegration-HowtoConfigureConnectionPool)

To integrate MyBatis and Spring with Altibase, you need to define the dataSource in Spring using the MyBatis module and connect it to Altibase.

This chapter explains how to connect Altibase using the MyBatis module in Spring.

## Setting dataSource by integrating MyBatis into Spring

---

To use Altibase together with Spring and MyBatis, configure the following in Spring’s configuration file (applicationContext.xml):

- SqlSessionFactory bean using the MyBatis module
- Transaction settings via transactionManager
- DataSource for the database
- Mapper Bean configuration: To perform the integration, you need the MyBatis-Spring integration modules, which are named as follows:

- mybatis-spring-1.x.x.jar: Using the mybatis-spring integration module requires Java version 1.5 or higher. Note that MyBatis and Spring versions may vary slightly depending on their releases. Please refer to the table below for detailed version compatibility information

| MyBatis Spring Integration Modules | MyBatis | Spring |
| --- | --- | --- |
| 1.0.0 and 1.0.1 | 3.0.1 to 3.0.5 | 3.0.0 or higher |
| 1.0.2 | 3.0.6 | 3.0.0 or higher |
| 1.1.0 or higher | 3.1.0 or higher | 3.0.0 or higher |

To use MyBatis together with Spring, you need to specify the MyBatis SqlSessionFactory bean and Mapper bean in Spring’s ApplicationContext.xml file.

The Mapper bean defines the methods that actually handle the queries, and it is processed via interfaces in the Spring framework.

In an environment integrating MyBatis and Spring, to configure the dataSource in Spring, you select one of the methods described in the 『Altibase_Spring_Integration_Guide』 document and specify the DB’s datasource name in the dataSource property of the SqlSessionFactory bean and TransactionManager bean.

Below is an example of specifying the dataSource, SqlSessionFactory bean, and TransactionManager bean in the applicationContext.xml file.

Example) ApplicationContext.xml file of altibase_mybatis_spring

```
…
<!-- DataSource configuration using the DriverManagerDataSource class -->
<bean id="dataSource" class="org.springframework.jdbc.datasource.DriverManagerDataSource">
   <property name="driverClassName" value="Altibase.jdbc.driver.AltibaseDriver" />
   <property name="url" value="jdbc:Altibase://192.168.1.35:36492/mydb" />
   <property name="username" value="sys" />
   <property name="password" value="manager" />
</bean>
…
<!-- TransactionManager bean configuration -->
<bean id= TransactionManager "
class="org.springframework.jdbc.datasource.DataSourceTransactionManager">
<property name="dataSource" ref="dataSource" />
</bean>
…
<!-- SqlSessionFactory bean configuration -->
<bean id="SqlSessionFactory" class="org.mybatis.spring.SqlSessionFactoryBean">
<property name="dataSource" ref="dataSource" />
<property name="typeAliasesPackage" value="com.altibase.test.domain" />
</bean>
```

This example is based on a Spring Template Project and was created using Maven. The libraries that users need to add are only the DB connection library (Altibase.jar), MyBatis-related library (mybatis-3.2.8.jar), and MyBatis-Spring integration library (mybatis-spring-1.2.1.jar). Spring-related libraries are handled automatically via Maven.

(The project was created using Spring MVC within the Spring Template Project, and when created this way, the generated pom.xml file automatically imports the necessary libraries using the dependency tags. Detailed information is provided in the appendix.)

## How to Configure Connection Pool

---

With Spring-MyBatis integration, the dataSource configuration can be set independently. Note that without Spring integration, MyBatis alone cannot use connection pools from other modules; you must integrate with Spring to use connection pools from other modules.

Below is an example of configuring a Connection Pool.

Example) applicationContext.xml file of altibase_mybatis_spring

```
...
<!—Altibase Connection Pool-->
<bean id="dataSource" class="Altibase.jdbc.driver.AltibaseConnectionPoolDataSource">
	<property name="URL" value="jdbc:Altibase://192.168.1.62:21020/mydb" />
	<property name="user" value="test" />
	<property name="password" value="test" />
</bean>
...

<!—Apache Connection Pool-->
<bean id="dataSource"
class="org.apache.commons.dbcp.BasicDataSource" destroy-method="close">
<property name="driverClassName" value="Altibase.jdbc.driver.AltibaseDriver" />
<property name="url" value="jdbc:Altibase://192.168.1.35:36492/mydb" />
<property name="username" value="sys" />
<property name="password" value="manager" />
<property name="initialSize" value="10" />
<property name="minIdle" value="25" />
<property name="maxIdle" value="30" />
<property name="maxActive" value="100" />
<property name="validationQuery" value="select 1 from dual" />
</bean>
```
