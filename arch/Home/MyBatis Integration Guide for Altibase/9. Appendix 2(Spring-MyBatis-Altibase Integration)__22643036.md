Based on the altibase_mybatis_spring example, this appendix provides a more detailed explanation of how to integrate Spring-MyBatis with Altibase. Note that the IDE used is Eclipse.

## Create DB Tables and Sequences

---

Create the following tables and sequences in the database.

```
create table users(
  user_no integer,
  user_name varchar(30),
  user_content varchar(200),
  reg_date date
);
```

## Package Naming Convention

---

The package name used in this example is based on a common naming convention and follows the structure `com.altibase.test`, as explained in the appendix. Each part of the package name has a specific meaning:

- **com**: The first part indicates the nature of the organization leading the project. “com” stands for “company.” For smaller groups or non-commercial organizations, “org” (organization) is often used.
- **altibase**: The second part represents the name of the company or organization. Since this document is created by Altibase, it uses "altibase."
- **test**: The third part reflects the specific artifact or purpose of the project. In this case, the project demonstrates general DML operations (Select/Insert/Delete/Update), so "test" is used.

## Creating the ApplicationContext File

---

In Spring development, the first thing you should do is create the **ApplicationContext** file, which is the Spring bean configuration file. The following section describes the contents of this configuration file.

```
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
	xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
	xmlns:context="http://www.springframework.org/schema/context"
	xmlns:tx="http://www.springframework.org/schema/tx"
	xmlns:p="http://www.springframework.org/schema/p"
	xsi:schemaLocation="http://www.springframework.org/schema/beans http://www.springframework.org/schema/beans/spring-beans-3.0.xsd
		http://www.springframework.org/schema/tx http://www.springframework.org/schema/tx/spring-tx-3.1.xsd
		http://www.springframework.org/schema/context http://www.springframework.org/schema/context/spring-context-3.0.xsd">

	<description>Example configuration to get you started.</description>

	<!-- Search for beans in the specified package -->
	<context:component-scan base-package="com.altibase.test.service" />

	 <!-- How to connect to ALTIBASE DB using Apache DBCP.
	      Apache DBCP provides properties for initializing the session pool, and it can create initialSize sessions on the first connection. -->
	<bean id="dataSource" class="org.apache.commons.dbcp.BasicDataSource" destroy-method="close">
        <property name="driverClassName" value="Altibase.jdbc.driver.AltibaseDriver" />
        <property name="url" value="jdbc:Altibase://192.168.1.62:21020/mydb" />
        <property name="username" value="test" />
        <property name="password" value="test" />
        <property name="initialSize" value="10" />
        <property name="minIdle" value="25" />
        <property name="maxIdle" value="30" />
        <property name="maxActive" value="100" />
        <property name="validationQuery" value="select 1 from dual" />
        <property name="testOnBorrow" value="false" />
    </bean>

	<!-- Enable transactions -->
	<bean id="txManager" class="org.springframework.jdbc.datasource.DataSourceTransactionManager">
		<property name="dataSource" ref="dataSource" />
	</bean>

	<!-- Define transaction annotations -->
	<tx:annotation-driven transaction-manager="txManager"/>

	<!-- Define SqlSessionFactory -->
	<!-- In the typeAliasesPackage property, specify the package containing domain classes referenced by SQL statements in mapper definition files (XML). -->
	<bean id="sqlSessionFactory" class="org.mybatis.spring.SqlSessionFactoryBean">
		<property name="dataSource" ref="dataSource" />
		<property name="typeAliasesPackage" value="com.altibase.test.domain" />
	</bean>

	<!-- Allow mapper classes created from mapper interfaces and mapper definition files to be injected into beans. -->
	<bean class="org.mybatis.spring.mapper.MapperScannerConfigurer">
		<property name="basePackage" value="com.altibase.test.persistence" />
	</bean>
</beans>
```

## Create the Mapper File

---

Create a Mapper file that defines the CRUD SQL statements for the Users table and the corresponding mapping methods. Since it follows the Spring approach, Dependency Injection is used. (UserMapper.xml, UserMapper.java) The Mapper will be created in the `com.altibase.test.persistence` package.

1. In the `altibase_mybatis_spring` project, right-click the `src` directory, then click New → Package to create a new package named `com.altibase.test.persistence`.

![additional2_9.png](https://docs.altibase.com/download/attachments/embedded-page/arch/9.%20Appendix%202(Spring-MyBatis-Altibase%20Integration)/additional2_9.png?api=v2)

2. Right-click the newly created package (com.altibase.test.persistence), select New - Interface, and create the UserMapper.java file.
3. Write the contents of the created interface file as follows.

```
package com.altibase.test.persistence;

import java.util.List;

import com.altibase.test.domain.UserVo;

public interface UserMapper {
	public List<UserVo> getAllUser();
	public UserVo getUserByNo(int user_no);
	public Integer insertUserData(UserVo userVo);
	public Integer deleteUserByNo(int user_no);
	public Integer updateUserByNo(UserVo userVo);

}
```

4. Right-click the newly created package (com.altibase.test.persistence), select New - File, and enter UserMapper.xml in File name.

![additional2_10.png](https://docs.altibase.com/download/attachments/embedded-page/arch/9.%20Appendix%202(Spring-MyBatis-Altibase%20Integration)/additional2_10.png?api=v2)

5. Write the following content in UserMapper.xml.

```
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
"http://mybatis.org/dtd/mybatis-3-mapper.dtd">

<mapper namespace="com.altibase.test.persistence.UserMapper">
	<select id="getAllUser" parameterType="Integer" resultType="UserVo">
		SELECT user_no as userNo,
		user_name as userName,
		user_content as userContent,
		reg_date as regDate
		FROM users
		WHERE user_no = #{userNo}
	</select>

	<select id="getUserByNo"  resultType="UserVo">
		SELECT user_no as userNo,
		user_name as userName,
		user_content as userContent,
		reg_date as regDate
		FROM users
	</select>

	<insert id="insertUserData" parameterType="UserVo">
		insert into
		users(user_no, user_name, user_content, reg_date)
		values(#{userNo}, #{userName}, #{userContent}, #{regDate})
	</insert>

	<update id="updateUserByNo" parameterType="UserVo">
		update users
		set user_name = #{userName},
		user_content = #{userContent},
		reg_date = #{regDate}
		where user_no = #{userNo}
	</update>

	<delete id="deleteUserByNo" parameterType="Integer">
		delete from users
		where user_no = #{userNo}
	</delete>
</mapper>
```

This method is specific to Spring and uses Dependency Injection (DI). In the application, SQL statements are handled through methods defined in the interface.

## Dependency Injection

---

Dependency Injection (abbreviated as DI) literally means injecting dependencies.

Dependency Injection is a technique from the GoF design patterns where the methods to be used by the user are defined in an interface and separated from the actual logic implementation.

With this approach, users can work with only the methods of the interface, and the actual implementation is injected later. This supports clearer separation of work and makes it easy to switch implementation classes.

## Application Development

---

1. Create the UserVo class (UserVo.java), a value object (VO) for the users table.
1-1. In the src/main/java directory of the altibase_mybatis_spring project, right-click and select New - Class.
1-2. Enter com.altibase.test.domain for Package and UserVo for Name.

![additional2_11.png](https://docs.altibase.com/download/attachments/embedded-page/arch/9.%20Appendix%202(Spring-MyBatis-Altibase%20Integration)/additional2_11.png?api=v2)

1-3. Write the following content in the UserVo.java file.

```
package com.altibase.test.domain;

import java.io.Serializable;
import java.util.Date;

@SuppressWarnings("serial")
public class UserVo implements Serializable {
	private Integer userNo;
	private String userName;
	private String userContent;
	private Date regDate;

	public UserVo() {

	}

	public UserVo(Integer userNo, String userName, String userContent, Date regDate) {
		this.userNo = userNo;
		this.userName = userName;
		this.userContent = userContent;
		this.regDate = regDate;
	}

	public Integer getUserNo() {
		return userNo;
	}

	public void setUserNo(Integer userNo) {
		this.userNo = userNo;
	}

	public String getUserName() {
		return userName;
	}

	public void setUserName(String userName) {
		this.userName = userName;
	}

	public String getUserContent() {
		return userContent;
	}

	public void setUserContent(String userContent) {
		this.userContent = userContent;
	}

	public Date getRegDate() {
		return regDate;
	}

	public void setRegDate(Date regDate) {
		this.regDate = regDate;
	}

	@Override
	public String toString() {
		return "User [no=" + userNo + ", name=" + userName + ", content=" + userContent
				+ ", date=" + regDate + "]";
	}
}
```

2. Create the interface and injection class files that execute the actual queries.
2-1. In the src/main/java directory of the altibase_mybatis_spring project, right-click and select New - Interface.
2-2. Enter com.altibase.test.service for Package and UserService for Name.

![additional2_12.png](https://docs.altibase.com/download/attachments/embedded-page/arch/9.%20Appendix%202(Spring-MyBatis-Altibase%20Integration)/additional2_12.png?api=v2)

2-3. Write the following content in the UserService.java file.

```
package com.altibase.test.service;

import java.util.List;
import com.altibase.test.domain.UserVo;

public interface UserService {
	public List<UserVo> getAllUser();
	public UserVo getUserByNo(int user_no);
	public Integer insertUserData(UserVo userVo);
	public Integer deleteUserByNo(int user_no);
	public Integer updateUserByNo(UserVo userVo);

```

2-4. Right-click the newly created package (com.altibase.test.service), then click New - Class to create the UserServiceImpl.java class file that handles the actual logic.

![additional2_13.png](https://docs.altibase.com/download/attachments/embedded-page/arch/9.%20Appendix%202(Spring-MyBatis-Altibase%20Integration)/additional2_13.png?api=v2)

2-5. Write the following content in the UserServiceImpl.java file.

```
package com.altibase.test.service;

import java.util.List;

import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;

import com.altibase.test.domain.UserVo;
import com.altibase.test.persistence.UserMapper;

@Service("userService")
public class UserServiceImpl implements UserService {

	@Autowired
	private UserMapper userMapper;
	private Integer res_count;

	public List<UserVo> getAllUser() {
		List<UserVo> userVos = userMapper.getAllUser();
		return userVos;
	}

	public UserVo getUserByNo(int user_no) {
		UserVo userVo = userMapper.getUserByNo(user_no);
		return userVo;
	}

	public Integer insertUserData(UserVo userVo) {
		res_count = userMapper.insertUserData(userVo);
		return res_count;
	}

	public Integer deleteUserByNo(int user_no) {
		res_count = userMapper.deleteUserByNo(user_no);
		return res_count;
	}

	public Integer updateUserByNo(UserVo userVo) {
		res_count = userMapper.updateUserByNo(userVo);
		return res_count;
	}
}
```

3. Write the Main class, where the actual program runs, in the Main.java file.

```
package com.altibase.test;

import java.util.Calendar;

import org.springframework.context.ApplicationContext;
import org.springframework.context.support.ClassPathXmlApplicationContext;

import com.altibase.test.domain.UserVo;
import com.altibase.test.service.UserService;

public class Main {

	private static UserService userService;

	public static void main(String[] args) {
		// TODO Auto-generated method stub
		int res_count = 0;

		ApplicationContext applicationContext = new ClassPathXmlApplicationContext("META-INF/spring/ApplicationContext.xml");
		userService = (UserService)applicationContext.getBean("userService");

		UserVo userVo = new UserVo();

		// Insert sample
		userVo.setUserNo(1);
		userVo.setUserName("psy");
		userVo.setUserContent("psy_content");
		userVo.setRegDate(Calendar.getInstance().getTime());
		res_count = userService.insertUserData(userVo);
		System.out.println("insert count = " + res_count);

		// Select sample
		userVo = userService.getUserByNo(1);
		System.out.println("no = " + userVo.getUserNo());
		System.out.println("name = " + userVo.getUserName());
		System.out.println("content = " + userVo.getUserContent());
		System.out.println("date = " + userVo.getRegDate());

		// Update sample
		userVo.setUserName("updated_psy");
		userVo.setUserContent("updated_psy_content");
		res_count = userService.updateUserByNo(userVo);
		System.out.println("update count = " + res_count);

		// Delete sample
		res_count = userService.deleteUserByNo(userVo.getUserNo());
		System.out.println("delete count = " + res_count);
	}
}
```

## Creating related JAR files

---

There are two ways to add JARs:

- Adding libraries via Maven
- Adding libraries the traditional way (Add External JARs in properties - Java Build Path)

The sample source is written choosing the Maven library management method. Since the second method, the traditional way, has already been explained above, this chapter will explain the Maven library management method. When you install Maven and create a Spring Template Project, a file called pom.xml is generated. This file manages the libraries.

![additional2_14.png](https://docs.altibase.com/download/attachments/embedded-page/arch/9.%20Appendix%202(Spring-MyBatis-Altibase%20Integration)/additional2_14.png?api=v2)

There are two ways to add libraries in the pom.xml file:

- Add libraries by directly entering tags in the pom.xml tab
- Add libraries using the Add button in the Dependencies tab

The method of directly entering tags involves clicking the pom.xml tab to open the XML file and adding the library by typing the tags manually, as shown in the image below. (The library used for testing is the Apache Commons DBCP library.)

![additional2_15.png](https://docs.altibase.com/download/attachments/embedded-page/arch/9.%20Appendix%202(Spring-MyBatis-Altibase%20Integration)/additional2_15.png?api=v2)

After adding the dependency and saving the XML file, verify that the library has been added to Maven Dependencies.

![additional2_16.png](https://docs.altibase.com/download/attachments/embedded-page/arch/9.%20Appendix%202(Spring-MyBatis-Altibase%20Integration)/additional2_16.png?api=v2)

To add a library using the Add button in the Dependencies tab, follow these steps:

1) In the pom.xml file, click the dependencies-Add button, which opens the following window. In the field labeled "Enter groupId, artifactId or sha1 prefix or pattern (star):", type the name of the library you want to add, and it will display libraries matching the entered name as shown below.

![additional2_17.png](https://docs.altibase.com/download/attachments/embedded-page/arch/9.%20Appendix%202(Spring-MyBatis-Altibase%20Integration)/additional2_17.png?api=v2)

2) When you click on a library shown in the Search Results, the available versions for that library will appear. Select the desired version and then click the OK button to add the library.

![additional2_18.png](https://docs.altibase.com/download/attachments/embedded-page/arch/9.%20Appendix%202(Spring-MyBatis-Altibase%20Integration)/additional2_18.png?api=v2)

You can verify that the library has been successfully added.

![additional2_19.png](https://docs.altibase.com/download/attachments/embedded-page/arch/9.%20Appendix%202(Spring-MyBatis-Altibase%20Integration)/additional2_19.png?api=v2)

When you save the file, the changes are applied, and the library is added.

![additional2_20.png](https://docs.altibase.com/download/attachments/embedded-page/arch/9.%20Appendix%202(Spring-MyBatis-Altibase%20Integration)/additional2_20.png?api=v2)
