# 3. Summary (Considerations for Altibase Backup Policy)
Source: https://docs.altibase.com/pages/viewpage.action?pageId=14647728
Updated: 2025-09-23T10:05:41.000+0900

- [Comparison by backup type](#id-3.Summary(ConsiderationsforAltibaseBackupPolicy)-Comparisonbybackuptype) - [Related documents](#id-3.Summary(ConsiderationsforAltibaseBackupPolicy)-Relateddocuments)

This chapter summarizes the characteristics of each backup type, which are organized in the following tables.

# Comparison by backup type

---

The following is a table comparing the pros and cons of each backup type.

| Classification | Logical backup | Physical backup | Incremental backup |  |  |
| --- | --- | --- | --- | --- | --- |
| aexport | iloader | Online backup | Offline backup |  |  |
| Characteristics | - Object-level backup/recovery<br>- Require backup only when changing object structure | - Table-level<br>- Record-level recovery is possible<br>- When point-in-time recovery is unnecessary<br>- When need to recover while the Altibase server is running | - When to minimize data loss<br>- When point-in-time recovery is required<br>- When there is no burden on the archive log mode operation<br>- When need to prepare for physical loss of files such as data files and log anchor files | - When Altibase server downtime for backup can be secured<br>- When to minimize recovery time | - When to minimize data loss<br>- When point-in-time recovery is required<br>- When there is no burden on the archive log mode operation<br>- When to prepare for physical loss of files such as data files and log anchor files<br>- When the DB performance degradation due to activating the 'Page Change Tracking" function can be sustained |
| Pros | - Altibase server operation possible during recovery | - Altibase server operation possible during recovery | - Point-in-time recovery is possible<br>- Possible to prepare for the physical failure of data files and log anchor files | - Minimize recovery time | - Point-in-time recovery is possible<br>- Possible to prepare for the physical failure of data files and log anchor files<br>- Save backup time compared to online backup<br>- Save backup space compared to online backup |
| Cons | - - | - Point-in-time recovery is unable | - Manage archive log files<br>- Operating Altibase server is unable during recovery | - - Operating Altibase server is unable during recovery | - Manage archive log files<br>- Operating Altibase server is unable during recovery |

| Backup type | Altibase server running status | Database mode | Backup file | Recovery point | Recovery target | Etc. |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Backup | Recovery |  |  |  |  |  |  |  |

| Offline backup | Stopped | - | Irrelevant | - Disk data file<br>- Memory checkpoint image file<br>- Log anchor file<br>- Online log file | - Backup point | - All databases |  |  |
