# 3. Summary (Considerations for Altibase Backup Policy)
Source: https://docs.altibase.com/pages/viewpage.action?pageId=14647728
Updated: 2025-09-23T10:05:41.000+0900

- [Comparison by backup type](#id-3.Summary(ConsiderationsforAltibaseBackupPolicy)-Comparisonbybackuptype) - [Related documents](#id-3.Summary(ConsiderationsforAltibaseBackupPolicy)-Relateddocuments)

This chapter summarizes the characteristics of each backup type, which are organized in the following tables.

# Comparison by backup type

---

The following table compares the characteristics, pros, and cons of each backup method.

| Classification | Logical backup: aexport | Logical backup: iLoader | Physical backup: online backup | Physical backup: offline backup | Incremental backup |
| --- | --- | --- | --- | --- | --- |
| Characteristics | - Object-level backup/recovery<br>- Backup is needed only when the object structure changes | - Table-level data backup<br>- Record-level recovery is possible<br>- Suitable when point-in-time recovery is unnecessary<br>- Suitable when recovery must be performed while the Altibase server is running | - Suitable when data loss must be minimized<br>- Suitable when point-in-time recovery is required<br>- Suitable when archive log mode operation is acceptable<br>- Prepares for physical loss of files such as data files and log anchor files | - Suitable when Altibase server downtime for backup can be secured<br>- Suitable when recovery time must be minimized | - Suitable when data loss must be minimized<br>- Suitable when point-in-time recovery is required<br>- Suitable when archive log mode operation is acceptable<br>- Prepares for physical loss of files such as data files and log anchor files<br>- Suitable when DB performance degradation from activating 'Page Change Tracking' is acceptable |
| Pros | - Altibase server can continue operating during recovery | - Altibase server can continue operating during recovery | - Point-in-time recovery is possible<br>- Can prepare for physical failures of data files and log anchor files | - Minimizes recovery time | - Point-in-time recovery is possible<br>- Can prepare for physical failures of data files and log anchor files<br>- Saves backup time compared to online backup<br>- Saves backup space compared to online backup |
| Cons | - | - Point-in-time recovery is not possible | - Archive log files must be managed<br>- Altibase server cannot operate during recovery | - Altibase server cannot operate during recovery | - Archive log files must be managed<br>- Altibase server cannot operate during recovery |

The following is a table comparing the features of each backup method in detail.

| Backup type | Method | Altibase server status during backup | Altibase server status during recovery | Database mode | Backup file | Recovery point | Recovery target | Other |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Logical backup | aexport | Running | Running | Irrelevant | - Database object creation script (`.sql` extension)<br>- Automation script (`.sh` extension) | - Backup point | - Object level |  |
| Logical backup | iLoader | Running | Running | Irrelevant | - FORM file for each table<br>- Text-format data file | - Backup point | - Table level<br>- Record level |  |
| Physical backup | Online backup | Running | Running<br>(CONTROL stage) | Archive mode | - Disk data files<br>- One memory checkpoint image file<br>- Log anchor files<br>- Archive log files | - Complete recovery<br>- Incomplete recovery | - Entire database<br>- Tablespace level | - Archive log files must be managed |
| Physical backup | Offline backup | Stopped | - | Irrelevant | - Disk data files<br>- Memory checkpoint image files<br>- Log anchor files<br>- Online log files | - Backup point | - Entire database |  |
| Incremental backup | Incremental backup | Running | Running<br>(CONTROL stage) | Archive mode | - Disk data files<br>- One memory checkpoint image file<br>- Log anchor files<br>- Archive log files<br>- `backupInfo` file | - Complete recovery<br>- Incomplete recovery | - Entire database<br>- Tablespace level | - 'Page Change Tracking' must be activated<br>- Archive log files must be managed |
