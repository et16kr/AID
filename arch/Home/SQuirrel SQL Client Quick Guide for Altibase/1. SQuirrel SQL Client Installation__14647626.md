# 1. SQuirrel SQL Client Installation
Source: https://docs.altibase.com/display/arch/1.+SQuirrel+SQL+Client+Installation
Updated: 2025-09-24T11:19:58.000+0900

- [1.1 Installation procedure](#id-1.SQuirrelSQLClientInstallation-1.1Installationprocedure)

This chapter describes how to install SQuirrel SQL Client. This document was prepared by downloading "Install jar of SQuirrel 3.7.1 for Windows/Linux/others" in the Windows environment.

# 1.1 Installation procedure

1. Download the SQuirrel SQL Client suitable for the user from the link below.
  [http://squirrel-sql.sourceforge.net/#installation](http://squirrel-sql.sourceforge.net/#installation)
2. Double-click the downloaded "squirrel-sql-3.7.1-standard.jar" to start the installation
  [https://jaist.dl.sourceforge.net/project/squirrel-sql/1-stable/3.7.1/squirrel-sql-3.7.1-standard.jar](https://jaist.dl.sourceforge.net/project/squirrel-sql/1-stable/3.7.1/squirrel-sql-3.7.1-standard.jar)
