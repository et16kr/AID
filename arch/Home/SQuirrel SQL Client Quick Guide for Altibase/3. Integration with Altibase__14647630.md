# 3.1 Database Connection Information Registration

1. Click Aliases -> New Alias in the main menu to register the database information to be accessed. If the Aliases menu is inactive, activate it by clicking Windows -> View Aliases.
2. Enter the information below.

  ```
  Name: Database connection name
  Driver: Select Altibase that was registered earlier.
  URL: Enter the host, port, database name to connect to.
  User Name: Database user name to use for connection.
  Password: Password of database user to use for connection.
  ```
3. After entering the information, click the "Test" button at the bottom to check if the entered connection information is correct.
  ![aa.png](https://docs.altibase.com/download/attachments/embedded-page/arch/3.%20Integration%20with%20Altibase/aa.png?api=v2)

# 3.2 Using Database

1. Click Aliases -> Connect on the main menu to open the connection window.
  ![image2017-8-1%2015_37_9.png](https://docs.altibase.com/download/attachments/embedded-page/arch/3.%20Integration%20with%20Altibase/image2017-8-1%2015_37_9.png?api=v2)
2. Click the "Connect" button to connect to the registered database.

# 3.3 Objects

If the connection is successful, a window consisting of two tabes is opened as shown below. The Object window is selected by default, and objects and detailed information existing in the connected database can be viewed.

![image2017-8-1%2015_40_15.png](https://docs.altibase.com/download/attachments/embedded-page/arch/3.%20Integration%20with%20Altibase/image2017-8-1%2015_40_15.png?api=v2)

# 3.4 SQL
