# 1. What is Spring?
Source: https://docs.altibase.com/pages/viewpage.action?pageId=14058412
Updated: 2025-09-23T10:11:38.000+0900

- [Features of Spring](#id-1.WhatisSpring?-FeaturesofSpring)

The Spring Framework is an open-source application framework and inversion of control container for the Java platform. The framework's core features can be used by any Java application, but there are extensions for building web applications on top of the Java EE (Enterprise Edition) platform. This is a lightweight container compared to EJB container, and manages the lifecycle of plain old Java objects (POJOs), and provides modules such as transaction management, logging, and security.

# **Features of Spring**

---

1. It is a lightweight container compared to J2EE.
2. It manages the life-cycle such as the creation and removal of Java objects, and the program can import and use the required objects from Spring without creating objects.
3. It supports IoC(Inversion of Control) and DI(Dependency Injection). That is, it can set the dependency of objects with the bean configuration file.
4. As it supports AOP (Aspect Oriented Programming), it is commonly used in many modules, but it can be applied to each module by separating functions (eg, functions such as transaction, logging, and security) that are not the core of the actual module.
5. It supports POJO, a general Java object that does not implement a specific interface or inherit a specific class like EJB. Therefore, it can be used in Spring without modifying the existing sources.
6. It provides a consistent method for transaction processing.
7. It provides various APIs.
