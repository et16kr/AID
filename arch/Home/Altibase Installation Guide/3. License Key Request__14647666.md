# 3. License Key Request
Source: https://docs.altibase.com/display/arch/3.+License+Key+Request
Updated: 2020-08-25T19:12:14.000+0900

---

Altibase is commercial software. To provide services through the Altibase DBMS, a license must be purchased.

If a license is purchased, a license certificate with warranty information can be issued. The certificate includes the license key suitable for the equipment where Altibase will be installed.

(To purchase a license, contact the relevant sales representative: [sales@altibase.com](mailto:sales@altibase.com).)

## Reference) How to Search MAC Address by OS

A license is required to install an Altibase package normally. To receive a license, the OS MAC address is required. Use the following methods to check the MAC address for each OS.
