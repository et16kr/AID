## Overview

The Altibase Package Installer is a Java-based installer. The user can easily install Altibase products such as database server, client libraries, and tools using the Altibase package installer.

## **Altibase Home Directory**

When installing using the Altibase Package Installer, a home directory and an APatch directory are created.

The Altibase home directory is the default directory where Altibase software is installed.

The default home directory is as follows.

- When installing the ALTIBASE HDB server product:

  ```
  $HOME/altibase-HDB-server-<version>
  ```
- When installing the ALTIBASE HDB client product:

  ```
  $HOME/altibase-HDB-client-<version>
  ```

## **APatch Directory**

Information about an Altibase product installed with the Altibase Package Installer is stored in the APatch directory under the Altibase home directory.

The directory is named APatch and is located under $ALTIBASE_HOME. It contains files that record installed product and patch version information. After an initial Altibase v7.1.0.0.0 installation, the file list is similar to the following.

```
-rw-------  1 altibase altibase  157724 Jun 16  2023 altibase_base_install.log
-rw-rw-rw-  1 altibase altibase     503 May 31  2023 patchinfo
-rw-rw-rw-  1 altibase altibase      90 May 31  2023 pkg_patch_0_0_0_0.txt
-rwx------  1 altibase altibase 4159980 Jun 16  2023 uninstall-p0_0_0_0
```

### **patchinfo file**

This file contains the following information:

- Information on the base release version and patch version of the currently installed Altibase product
- Information on the environment in the product such as operating system, operating system patch, C/C++ compiler and Java compiler are built

```
PRODUCT_SIGNATURE=server-7.1.0-64-release
PATCH_VERSION=0_0_0_0
=======  OS INFO  =======
Linux rhel6-x64 2.6.32-71.el6.x86_64 #1 SMP Wed Sep 1 01:33:01 EDT 2010 x86_64 x86_64 x86_64 GNU/Linux
=======  PATCH INFO  =======
2.6.32-71.el6.x86_64
=======  COMPILER INFO  =======
gcc version 4.6.3 (GCC)
glibc 2.12
=======  JAVA INFO  =======
java version "1.5.0_22"
Java(TM) 2 Runtime Environment, Standard Edition (build 1.5.0_22-b03)
Java HotSpot(TM) 64-Bit Server VM (build 1.5.0_22-b03, mixed mode)
```

### **pkg_patch_x_x_x_x.txt file**

This file is automatically created with the name pkg_patch_<installed version number>.txt each time a product is patched. This file contains the revision number of the source code modified to make the patch.

- The following example shows the APatch directory after installing base release 7.1.0.0.0.

  ```
  $ ls -la
  -rw-rw-rw-  1 altibase altibase      90 May 31  2023 pkg_patch_0_0_0_0.txt
  ```
- The following example shows the information of the APatch directory after installing patch 7.1.0.0.10.

  ```
  $ ls -la
  -rw-rw-rw-  1 altibase altibase      90 May 31  2023 pkg_patch_0_0_0_0.txt
  -rw-r--r--  1 altibase altibase      90 May 19 03:54 pkg_patch_0_0_0_10.txt

  $ cat pkg_patch_0_0_0_10.txt
  Repository: /altidev4/tags/altibase_7_1_0_0_10_tag/
  Revision: xxxxx
  Last Changed Rev: xxxxx
  ```

### altibase_base_install.log file

All the actions during the most recent installation are recorded in this file.

### Backup directory

When installing the patch, the Altibase Package Installer creates a backup of the file to which the patch is applied and saves it in the $ALTIBASE_HOME/APatch directory. In this directory, separate backup directories created for each patch are located. These backup files will be used later to roll back the patch.

In addition, executable files used when uninstalling or rolling back a patch are installed in the $ALTIBASE_HOME/APatch directory when installing the product or applying a patch.

* Note 1: On the HP platform, automatic backup and rollback are not supported when patching the installer. The user must manually back up data and log files.

* Note 2: Only files installed through the package installer are backed up to this backup directory, and files created after product installation, such as data files and log files, are not backed up.

The following shows the APatch directory after installing base release 7.1.0.0.0.

```
$ ls -la
-rw-------  1 altibase altibase  157724 Jun 16  2023 altibase_base_install.log
-rw-rw-rw-  1 altibase altibase     503 May 31  2023 patchinfo
-rw-rw-rw-  1 altibase altibase      90 May 31  2023 pkg_patch_0_0_0_0.txt
-rwx------  1 altibase altibase 4159980 Jun 16  2023 uninstall-p0_0_0_0
```

- `uninstall-p0_0_0_0`: executable file used to uninstall base release 7.1.0.0.0.

The following shows the APatch directory after applying patch 7.1.0.0.10.

```
$ ls -la
-rw-------  1 altibase altibase   38817 May 24 08:10 altibase_base_install.log
-rw-r--r--  1 altibase altibase     503 May 19 03:54 patchinfo
-rw-rw-rw-  1 altibase altibase      90 May 31  2021 pkg_patch_0_0_0_0.txt
-rw-r--r--  1 altibase altibase      90 May 19 03:54 pkg_patch_0_0_0_10.txt
drwx------  3 altibase altibase    4096 May 24 08:10 rollback-p0_0_0_10
-rwx------  1 altibase altibase 4159911 Jan 28  2022 uninstall-p0_0_0_0
-rwx------  1 altibase altibase 4159851 May 24 08:10 uninstall-p0_0_0_10
```

- `rollback-p0_0_0_10`: directory where backups of files patched by 7.1.0.0.10 are stored.
- `uninstall-p0_0_0_10`: executable used to remove patch 7.1.0.0.10 and revert to the version before the patch installation. Files used for rollback are stored in the `rollback-p0_0_0_10` directory.
