# WEBLOGIC Integration Guide for Altibase
Source: https://docs.altibase.com/display/arch/WEBLOGIC+Integration+Guide+for+Altibase
Updated: 2020-05-15T15:48:45.000+0900

## Overview

This is a technical document for integrating with Altibase and WebLogic. It also covers running a simple web application that works with Altibase on the assumption that WebLogic is installed.

This document is based on WebLogic 12.1.3.0 on the Windows platform, and all contents may differ depending on the version. For basic environments such as WebLogic installation and domain creation, refer to Oracle's documentation and management console help provided when installing WebLogic (Administration Console).

[Oracle Documentation Library](http://docs.oracle.com/middleware/1213/wls/index.html)

In addition to this document, the documents to be referenced during development are as follows.

- JAVA Development Guide
- JBOSS Integration Guide for Altibase
- TOMCAT Integration Guide for Altibase
- WEBSPHERE Integration Guide for Altibase
- WEBLOGIC Integration Guide for Altibase
- Spring Integration Guide for Altibase
- HIBERNATE Integration Guide for Altibase
- iBatis Integration Guide for Altibase
