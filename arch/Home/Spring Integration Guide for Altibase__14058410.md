# Spring Integration Guide for Altibase
Source: https://docs.altibase.com/display/arch/Spring+Integration+Guide+for+Altibase
Updated: 2020-07-31T15:19:35.000+0900

# Overview

This technical document describes how to integrate with Altibase and Spring. In this document, Spring Framework 3.2.x and ALTIBASE 6.3.1 were used, Eclipse as the development IDE. Examples are provided for each chapter in addition to the document.

For errors and improvements related to this document, please contact the technical support portal or technical support center

- Technical support portal: [http://support.altibase.com](http://support.altibase.com/) > Technical Knowledge > Q&A
- Technical support center: 02-2082-1114

Old Version: ALTIBASE_Spring_Integration Guide_2.5.pdf (spring v2.5)
