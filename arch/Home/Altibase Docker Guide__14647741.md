# Overview

---

This document describes how to create and service an Altibase container using the Docker images.

This document also describes how to create Altibase Docker images based on Docker version 19.03.2 and create a container for service.

- Altibase version 7.1.1 and later
- Docker version 19.03.2 or later

For errors and improvements related to this document, please contact the technical support portal or technical support center.
