# 1. ALTIBASE HDB PHP Module Reference
Source: https://docs.altibase.com/display/arch/1.+ALTIBASE+HDB+PHP+Module+Reference
Updated: 2020-08-11T17:19:33.000+0900

The data types supported by PHP are as follows: resource, int, bool, double, float, string, array, HashTable

The port number of the Altibase server and the port number in `db.php` of the sample program provided by Altibase must match.
