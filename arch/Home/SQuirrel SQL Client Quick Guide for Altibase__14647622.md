# Overview

---

This document describes how to install the SQuirrel SQL Client and integrate with Altibase with Altibase JDBC.

The test environment of this document is as follows.

- Altibase : Altibase version 6 or later
- OS : Linux ( 2.6.32-504.el6.x86_64 )
- SQuirrel: 3.7.1 standard
