# TOMCAT Integration Guide for Altibase
Source: https://docs.altibase.com/display/arch/TOMCAT+Integration+Guide+for+Altibase
Updated: 2020-08-05T09:47:58.000+0900

This technical document describes how to integrate Altibase and TOMCAT. The test environment uses Altibase v6.3 or later and TOMCAT v7.0.

For errors and improvements related to this document, please contact the technical support portal or technical support center

- Technical support portal: [http://support.altibase.com](http://support.altibase.com/) > Technical Knowledge > Q&A
