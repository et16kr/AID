# Altibase Window ADO.NET Development Guide
Source: https://docs.altibase.com/display/arch/Altibase+Window+ADO.NET+Development+Guide
Updated: 2021-02-19T15:51:02.000+0900

# Overview

---

This document describes how to develop Altibase applications in a Windows ADO.NET environment.

It is recommended to read the following document in advance for detailed instructions on using the ADO.NET interface with Altibase.

- Application Program Interface User's Manual

The test environment of this document is as follows.

- Altibase version: Altibase 6.5.1
- OS: Windows 7
- Visual Studio 2010 C#

For errors and improvements related to this document, contact the technical support portal or technical support center.

- Technical support portal: [http://support.altibase.com](http://support.altibase.com/) -> Technical Knowledge -> Q&A
- Technical support center: 02-2082-1114
