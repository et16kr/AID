Among the various ways to start and stop a WebLogic Server instance, this section describes how to use the script or batch files in `$DOMAIN_HOME/bin`.

Each domain provides separate start and stop scripts for the Administration Server and Managed Servers.

- Administration Server: `startWebLogic.cmd`, `stopWebLogic.cmd`
- Managed Server: `startManagedWebLogic.cmd`, `stopManagedWebLogic.cmd`

## Start

Run `startWebLogic.cmd` to start the Administration Server for the domain. The following output shows the message format when startup completes normally.

```
$ startWebLogic.cmd
.

*  console at http:\\hostname:port\console        *
***************************************************
... syncopation ...

<2014. 10. 30 4:27:13 PM KST> <Notice> <WebLogicServer> <BEA-000331> <Started the WebLogic Server Administration
 Server "myserver" for domain "mydomain" running in development mode.>

<2014. 10. 30 4:27:13 PM KST> <Notice> <WebLogicServer> <BEA-000365> <Server state changed to RUNNING.>
```

## Shutdown

Run `stopWebLogic.cmd` to shut down the Administration Server for the domain. The following output shows the message format when shutdown completes normally.

```
$ stopWebLogic.cmd
Stopping Weblogic Server...
... syncopation ...
Connecting to t3://IBM-1DA5AF93847:7001 with userid weblogic ...
Successfully connected to Admin Server 'AdminServer' that belongs to domain 'mydomain'.
... syncopation ...
Shutting down the server AdminServer with force=false while connected to AdminServer ...
Disconnected from weblogic server: AdminServer
Exiting WebLogic Scripting Tool.
Done
Stopping Derby Server...
```

For shutdown, normal termination cannot be guaranteed from the shutdown script result alone.

If the related process still exists even though the shutdown message is normal, check and correct the WebLogic Server instance log.

## **JDBC Driver Settings**

To create a JDBC data source, the relevant JDBC driver must be set in WebLogic. This section describes overall information about JDBC Driver settings.

### How to get the Altibase JDBC Driver

The Altibase JDBC driver is provided as a single file called Altibase.jar.

It is provided with the Altibase Server package by default, so it can be obtained from the `$ALTIBASE_HOME/lib` directory of the operating system account where Altibase is installed.

`Altibase.jar` and `Altibase5.jar` are provided starting from Altibase 5. `Altibase5.jar` is used to connect to Altibase 5 and earlier versions.

Therefore, when only one Altibase server is connected, or when multiple Altibase servers of the same version are connected, use `$ALTIBASE_HOME/lib/Altibase.jar`.

The latest ALTIBASE JDBC driver can be found on [http://support.altibase.com](http://support.altibase.com).

### How to check the Altibase JDBC Driver Version

In order to determine whether the Altibase Server and the Altibase JDBC Driver are compatible, the version of the Altibase Server and Altibase JDBC Driver must be compared to check whether the CM (Communication) protocol matches.

Check the Altibase server version as follows.

```
$ altibase -v
version 6.3.1.2.7 X86_64_LINUX_redhat_Enterprise_ES4-64bit-6.3.1.2.7-release-GCC3.4.6 (x86_64-unknown-linux-gnu) Oct  8 2014 09:16:24, binary db version 6.2.1, meta version 6.3.1, cm protocol version 7.1.1, replication protocol version 7.4.1
```

Check the Altibase JDBC driver version as follows.

```
$ java -jar Altibase.jar
JDBC Driver Info : Altibase Ver = 6.3.1.2.6 for JavaVM v1.4, CMP:7.1.1, Oct  6 2014 13:54:56
```

The Altibase server and Altibase JDBC driver are compatible when the server `cm protocol version` matches the JDBC driver `CMP` value.

Generally, the Altibase JDBC driver file included in the Altibase server package is used for compatibility, but it is recommended to use the latest compatible Altibase JDBC driver file whenever possible.

### How to set the JDBC Driver to be used in WebLogic

To use a specific JDBC driver in WebLogic, the relevant files must be added to the CLASSPATH of the domain management server.

There are two ways to configure it. Either method can be used, but the domain Administration Server must be restarted after configuration.

The following examples configure Altibase 5 and another Altibase version at the same time. When integrating Altibase servers of the same version, only one JDBC driver needs to be configured.

1. Place the JDBC driver files in `$DOMAIN_HOME/lib`.

After the JDBC driver files are placed in `$DOMAIN_HOME/lib`, they are automatically added to the `CLASSPATH` when the domain Administration Server starts. The following message is displayed.

```
...
<2010. 12. 14 4:48:24 PM KST> <Notice> <WebLogicServer> <BEA-000395> <Following extensions directory contents added to the end_of_the_classpath:C:\Oracle\Middleware\user_projects\domains\mydomain\lib\Altibase.jar;C:\Oracle\Middleware\user_projects\domains\mydomain\lib\Altibase5.jar>
...
```

2. Add JDBC driver files directly to the `CLASSPATH` of `startWebLogic.cmd`.

Open `startWebLogic.cmd` for the domain Administration Server, add the JDBC driver files directly to the `CLASSPATH` item, and restart the server.

```
...
set CLASSPATH=%SAVE_CLASSPATH%;C:\WebLogic_lib\Altibase5.jar;C:\WebLogic_lib\Altibase.jar
...
```
