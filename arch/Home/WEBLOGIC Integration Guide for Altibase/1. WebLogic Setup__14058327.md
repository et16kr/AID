# 1. WebLogic Setup
Source: https://docs.altibase.com/display/arch/1.+WebLogic+Setup
Updated: 2025-09-24T09:08:56.000+0900

- [Download](#id-1.WebLogicSetup-Download) - [Installation](#id-1.WebLogicSetup-Installation) - [Creating Domain](#id-1.WebLogicSetup-CreatingDomain)

A brief procedure to create a domain after downloading and installing WebLogic will be described using WebLogic 12.1.3.0 on the Windows platform as an example.

### Download

As BEA Systems, which developed WebLogic in April 2008, was acquired by Oracle, WebLogic can be downloaded from the Oracle middleware product download page from version 9 or later.

[http://www.oracle.com/technetwork/middleware/downloads/index.html](http://www.oracle.com/technetwork/middleware/downloads/index.html)

After accepting the license agreement from the relevant web page, download the most recently released WebLogic for the operating system platform.

![weblogic12c_download.png](https://docs.altibase.com/download/attachments/embedded-page/arch/1.%20WebLogic%20Setup/weblogic12c_download.png?api=v2)

### Installation

When the downloaded file is running, the WebLogic automatic installer is running.

Install WebLogic in the following procedure.

1.Select Next on the start screen and specify the path where WebLogic and related middleware products will be installed.

![weblogic12c_install1.png](https://docs.altibase.com/download/attachments/embedded-page/arch/1.%20WebLogic%20Setup/weblogic12c_install1.png?api=v2)![weblogic12c_install2.png](https://docs.altibase.com/download/attachments/embedded-page/arch/1.%20WebLogic%20Setup/weblogic12c_install2.png?api=v2)![weblogic12c_install3.png](https://docs.altibase.com/download/attachments/embedded-page/arch/1.%20WebLogic%20Setup/weblogic12c_install3.png?api=v2)

2. Check and Install the installation summary

(The installation path of the WebLogic specified here is later identified by the environment variable WL_HOME.)

![1.png](https://docs.altibase.com/download/attachments/embedded-page/arch/1.%20WebLogic%20Setup/1.png?api=v2)![2.png](https://docs.altibase.com/download/attachments/embedded-page/arch/1.%20WebLogic%20Setup/2.png?api=v2)

3. Confirm whether the installation is completed

![3.png](https://docs.altibase.com/download/attachments/embedded-page/arch/1.%20WebLogic%20Setup/3.png?api=v2)

### Creating Domain

The domain can be created by using the Configuration Wizard.

Install WebLogic in the following procedure.

1.Run the installation wizard to create a new domain. (The user can set the domain location.)

![4.png](https://docs.altibase.com/download/attachments/embedded-page/arch/1.%20WebLogic%20Setup/4.png?api=v2)![5.png](https://docs.altibase.com/download/attachments/embedded-page/arch/1.%20WebLogic%20Setup/5.png?api=v2)

2. Enter the user name and password for the management server.

(The installation path of the domain specified here is later identified by the environment variable DOMAIN_HOME.)

![6.png](https://docs.altibase.com/download/attachments/embedded-page/arch/1.%20WebLogic%20Setup/6.png?api=v2)

3. Set the start mode and JDK of the domain Administration Server.

- Start Mode

For testing purposes, select "Development Mode".

In development mode, web applications can be automatically deployed and changed through `$DOMAIN_HOME/autodeploy`, making testing easier.

- JDK

When the start mode is selected, the appropriate JDK is automatically selected, so it does not need to be selected separately unless there is a special case.

![12.png](https://docs.altibase.com/download/attachments/embedded-page/arch/1.%20WebLogic%20Setup/12.png?api=v2)

4. If there is a specific change the user wants to make, such as receiving port of the management server, select the relevant item, and change it. If not, skip (NEXT).

For reference, the management server uses port 7001 by default.

![13.png](https://docs.altibase.com/download/attachments/embedded-page/arch/1.%20WebLogic%20Setup/13.png?api=v2)

5. When domain creation is complete, check the "Start Management Server" option and select Done.

![14.png](https://docs.altibase.com/download/attachments/embedded-page/arch/1.%20WebLogic%20Setup/14.png?api=v2)

6. Installation Complete

![15.png](https://docs.altibase.com/download/attachments/embedded-page/arch/1.%20WebLogic%20Setup/15.png?api=v2)
